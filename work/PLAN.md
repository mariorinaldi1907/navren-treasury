# Navren product plan
Target: Singapore SME finance manager paying ASEAN suppliers. Problem: hidden total cost, fragmented quotes, uncertain arrival and manual reconciliation. Proposition: one instruction, constrained route comparison, explicit approval, tracking and reconciliation.
Names considered: Navren, Meridia, Ternwell. Navren selected for a compact navigational identity; basic public name search is not trademark clearance.
MVP: treasury overview; payment instruction; comparison and explanation; review; simulated timeline and ledger; searchable transactions; suppliers; demo integrations; controls and company settings. No real funds, licenses, external integrations, LLM decisions or production backend.
Design: warm ivory canvas, wine navigation and type, copper accents, compact tables, serif editorial headings, restrained green states. Responsive navigation and clearly labeled controls.
Financial model: source principal converted at quoted rate, fees added to debit. FX cost = principal × spread; total economic cost = FX cost + transfer + intermediary estimate. Quote savings compare economic cost against bank baseline, not cash balance. No double-counting FX spread in debit.
Constraints: mandatory screening and corridor availability, deadline, authorization, funds and quote expiry. Ranking eligible routes with cost/deadline/reliability/FX/operational weights. A cheaper slow route remains ineligible until deadline permits it. Above S$100k needs second approval and cannot execute in demo.
Flow: overview → supplier/invoice/amount/deadline/priority → quote retrieval → compare four normalized quotes → select eligible route → explicit review → send simulation → event timeline → accounting match.
State: typed shared fixtures and pure quote service. Local browser persistence for completed payments/settings; reset available. Fixed demo clock 2 Oct 2026 10:00 SGT for repeatability; quote expiry uses actual elapsed time.
QA: pure calculation and guard tests; browser primary journey, blocked routes, expiry, deadline, filters and navigation; laptop/mobile screenshots; keyboard checks and console audit; PM/polish review.
Research: https://www.bis.org/project/nexus and https://www.mas.gov.sg/regulation/payments/regulations-and-guidance. Regional IPS displayed as a concept, no production Nexus claim. Screening is simulated and neither licensing nor regulatory compliance is asserted.
